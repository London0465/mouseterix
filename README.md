# Mousetérix - Manual de trinchera para galos en entornos romanos

Crónicas y comandos reales para sobrevivir a auditorías, code reviews eternos, monolitos y frameworks propietarios.

---

## ¿Qué es esto?

Mouse-TU es un droide de cocina que lucha contra el Imperio Romano del código. Cada episodio es una historia real disfrazada de chiste. Y detrás de cada chiste, hay un comando que funciona.

Este repositorio contiene:
- Los 6 episodios completos (en `/episodios`)
- Los comandos que usó Mouse (en `/manuales/comandos.md`)
- Instrucciones para copiar, pegar y ejecutar sin que los romanos se den cuenta

---

## Cómo usar esto

1. Si sos desarrollador: andá a `/manuales/comandos.md` y copiá lo que necesites.
2. Si sos jefe: leé los episodios y reíte. Después andá a `/manuales/comandos.md` y entendé por qué tu equipo te quiere.
3. Si sos romano: no hay nada que ver acá. Seguí de largo.

---

## Episodios

- 01 - El análisis de brechas (cómo enjaular un framework ajeno)
- 02 - El code review eterno (cómo procesar 300 comentarios sin volverte loco)
- 03 - El despliegue en el Coliseo (cómo romper todo y arreglarlo en 47 segundos)
- 04 - El monolito del menhir (cómo destruir 20.000 líneas de mierda)
- 05 - La reunión del Sprint Review con César (cómo inventar métricas que nadie va a revisar)
- 06 - El gran merge final (cómo independizarte y dejar un 404)
